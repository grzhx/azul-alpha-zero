# 人机对战手动发牌

勾选“手动发牌（新对局生效）”后开始新对局。第一轮以及之后每轮结算后，双方等待玩家填写 5 个工厂各 4 个槽位，点击“确认发牌”后继续。

槽位按工厂 1 至 5、每厂从左到右作为抽取顺序；先用完旧袋才补入弃砖。页面显示当前袋与弃砖的颜色计数，后端再次严格校验；非法提交不会修改局面。无人可取砖且袋/弃砖都耗尽时剩余槽位为空。正常合法双人对局通常可填满 20 格。

手动模式在开局选定，修改 AI 搜索参数不会改变该模式；换回随机发牌请取消勾选后重新开局。撤回功能可以从待发牌状态回到上一次人类行动前。终局不再发牌。

手动控制的是实际对局的抽砖，AI 搜索仍按原规则模拟未知未来的随机补砖，不会预知你随后选择的颜色。

前端使用 `build-play/azul.dll`（存在时），与训练 DLL 隔离。重新构建：

```powershell
./scripts/build-msvc.ps1 -Configuration Release -OutputDirectory build-play
./.venv/Scripts/python.exe scripts/play.py --port 8766
```
